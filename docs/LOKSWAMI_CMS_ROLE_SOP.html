Shared working rules

Save safely. Hand off once.

Article draft safety

1
Watch the save chip. Saved is the safest point to leave.
2
Use Save draft or Ctrl+S / Cmd+S before a handoff or long pause.
3
The same tab resumes its own draft quietly. Another tab/session may show one inline recovery notice.
4
Choose Restore recovery copy if needed, or Discard old copy if stale.
5
The Article form and publish action stay locked until that recovery choice is resolved.

No repeated prompt during editing

Inserting an image or table is an editor action. It should not submit the form or repeatedly show draft recovery.

Always wait for image/audio upload completion before submitting, refreshing, or closing the tab.

Version conflict

Stop editing. Compare with the saved version and reload the latest Article before changing workflow status. Do not repeatedly force Save or Publish.

Story saving is different

Reporter Story forms do not use browser autosave or the Article recovery notice. Save Draft is the server recovery point.

Current Story Save Draft still requires at least one image and one video. Leaving before saving can lose form data.

Before every workflow action

  • Finish uploads.
  • Save content changes.
  • Read the newest desk note.
  • Use one clear status action.
  • Confirm the success message.

Reporter SOP

Create the reporting package

DashboardMy WorkMy StoriesMedia

Reporter creates a Story package—not a standalone Article. A claimed/assigned Copy Editor may build the linked Article during desk review; Copy Editor/Admin completes the Article handoff.

1
Open My Stories → New Story, or start from My Work.
2
Enter Story Title, Video Script, Category, Location Tag, Reporter Notes, and Source Info. The signed-in Reporter is the author.
3
Select Source is confidential when source details must remain internal.
4
Upload at least one JPG/PNG/WEBP image and one MP4. The first image becomes the cover.
5
Wait for upload and video verification. Preview, replace, or remove the wrong media.
6
Choose Save Draft to keep it private or Submit For Review for desk handoff.

Upload limits

  • 1–5 images; maximum 5 MB each
  • 1–10 MP4 videos; maximum 1.9 GB each
  • Reporter Media library accepts images; Story editor handles MP4
Important: Save Draft is not a partial text-only save today. The required image + video package must be present.

When changes are requested

  1. Open the item from My Work/My Stories.
  2. Read the highlighted return reason and latest desk note.
  3. Correct every requested item.
  4. Choose Save Changes first.
  5. Add an optional workflow note and Submit For Review.

Submitted and later stages are read-only unless the desk returns the Story as Changes Requested.

Reporter cannot

  • Publish, approve, schedule, archive, delete, or assign
  • Create a linked/standalone Article
  • Edit Copy Desk QA or upload Article audio/TTS
  • Use Review Queue, Copy Desk, Team, Analytics, Push Alerts, or Settings

Reporter handoff

  • Names, numbers, dates, location, and spellings verified
  • Source, rights, and credit information recorded
  • Confidential source marked internal
  • Correct image/video finished uploading
  • Script matches the media
  • Reporter notes explain desk context
  • Package previewed before submission
  • Submitted once—no duplicate Story

Copy Editor SOP

Verify, improve, and hand off

DashboardMy WorkCopy DeskArticlesStoriesVideosSocial Posts (read-only)Media
1
Open Copy Desk.
2
For an unassigned Submitted Story choose Claim Story; for your assigned work choose Start Review.
3
Open it and download Reporter assets when needed.
4
Check source, location, notes, confidentiality, title, facts, media, captions, and credits.
5
Complete proofread, fact-check, headline, image optimization, and Copy Editor notes.
6
Save content changes before any workflow action.

Choose the correct exit

Move To Copy Edit
Keep polishing assigned work.

Request Changes
Return incomplete reporting with one specific actionable reason.

Ready For Approval
Hand clean, complete work to Admin. It then becomes read-only for Copy Editor.

Direct Article

  1. Open Articles → Create Article.
  2. Choose an existing category, then complete Compose, Quality, Media, SEO, and Publish.
  3. Resolve all readiness blockers.
  4. Choose Submit for review.

Copy Editor can create an Article but cannot publish it directly.

Publication production notes

  • Send page, OCR, hotspot, caption, or linked-story quality notes to Super Admin.
  • Super Admin applies those notes in the publication CMS and owns release.
  • All publication CMS access is Super Admin only. Assignment does not grant Copy Editor access.
  • E-Magazine is a monthly issue, not a daily E-Paper edition.

Copy Editor quality gate

  • Facts, quotes, headline, and language checked
  • Source/credit and sensitivity notes present
  • Alt text, caption, crop, and image credit checked
  • Copy notes explain material changes
  • Return reason is specific and actionable
  • Clean work is Ready For Approval—not Published
Copy Editor cannot manage users, use Push Alerts, publish content/E-Paper, or open Admin/System settings. Social Posts is read-only; Admin/Super Admin generates, approves, or dispatches.

Admin SOP

Run the desk and own release

Review QueueAssignmentsContent QueueCopy DeskPush AlertsTeamAnalyticsOperations

Daily desk

1
Check Dashboard urgent counts, blocked work, failed work, and due items.
2
Open Review Queue and Assignments.
3
Choose Assign; set staff member, priority, and due time.
4
Use Content Queue to track work through every status.
5
Use Request Changes with a clear reason; use Reject only when intentionally stopping the item.

Approve and release

1
Open Ready For Approval work.
2
Read Reporter notes, Copy notes, source information, and activity.
3
Preview public presentation on desktop and mobile.
4
Choose Approve, then Schedule or Publish Now.
5
Verify the public URL before Push Alerts or social distribution.

Admin owns

Articles, Stories, Videos, Social Posts, Media, Polls, Categories, Contact Messages, Team, Analytics, AI Ops, Newsroom Settings, Push Alerts, and Operations Center.

Super-Admin boundary

E-Papers/E-Magazines, System Settings, Revenue, Business Value, Audit Log, Permission Review, Operations Diagnostics, and leadership-report management. Admin cannot create, edit, or remove a Super Admin.

Team safety

  • Assign the least-privileged correct role
  • Admin may manage Admin, Reporter, and Copy Editor
  • Deactivate staff access promptly when duties end
  • Never grant Super Admin for daily publishing work
Distribution order: Publish → open public page → verify headline/image/body/audio/links → test Share link → then prepare/copy Push Alert text or create a social post. Final push delivery uses the approved external channel.

Article workflow

Create a release-ready Article

Editor sequence

1
Compose: title, summary, body, author, category, and location.
2
Quality: source attribution, Reporter/Editor notes, flags, and readiness.
3
Media: featured image, alt text, caption, credit, and optional listen audio.
4
Structure: use inline Image or Table controls where they improve reading.
5
SEO: title, description, slug/canonical, keywords, and social image.
6
Publish: resolve readiness blockers and select Submit, Schedule, or Publish according to role.

Breaking news

Admin must upload the required breaking audio before publishing a Breaking Article. Confirm headline/location match the audio.

Do not refresh while the image or audio upload status is active.

Editorial check

  • Headline accurate and supportable
  • Summary matches body
  • Author/category/location complete
  • Names, dates, figures, quotes, links verified
  • Source attribution and correction notes present

Media/accessibility check

  • Featured image sharp and relevant
  • Alt text, caption, and credit complete
  • Inline images/tables work on mobile
  • Listen/breaking audio works where used
  • No upload remains in progress

SEO, brand, and public verification

  • Slug and canonical URL correct
  • SEO title/description/social image ready
  • News sitemap option correct
  • Lokswami branding/header present
  • WhatsApp/Facebook/X/LinkedIn links work
  • Copy Link opens the published page
  • Prepared alert text matches headline and URL
  • Desktop and mobile public page checked
If public presentation or sharing is wrong, do not prepare or externally deliver an alert. Correct the content/media, republish if authorized, and verify again.

E-Paper and E-Magazine

From PDF to smooth public reader

Draft UploadPages ReadyOCR ReviewHotspot MappingReady To PublishPublished

Super Admin upload and release

1
Open E-Papers or E-Magazines → New Upload.
2
Enter edition/issue metadata and upload the PDF.
3
Wait for page conversion. Never publish while pages are processing.
4
Clear missing-image, OCR, hotspot, linked-story, and readiness blockers.
5
Publish only from Ready To Publish.

Super Admin production QA

  • Every expected page is present
  • OCR text manually reviewed
  • Hotspot boxes match story areas
  • Headline and readable text are clean
  • Missing pages/blockers recorded in notes
  • Clean edition marked Ready To Publish

Public reader check

  • Open first, middle, and final page.
  • Turn pages on desktop and mobile.
  • Test search/OCR text where available.
  • Open several hotspots and linked stories.
  • Use Share and open the copied public link.

Publication cadence

E-Paper: edition-based daily/news cycle.

E-Magazine: monthly issue product using the same production safeguards.

OCR is assistance, not final copy. A human must review names, headings, punctuation, and article boundaries before accepting OCR or creating linked Story drafts.

Reporter close

No finished package left only in Draft; returned work has a clear next action.

Copy Editor close

Every claimed item is saved and actively reviewing, returned with a reason, or ready.

Admin close

Urgent queues, schedules, failed uploads, and public releases are checked.

One final rule: no external alert or campaign share points to a page that the Admin has not opened and verified after publication.
